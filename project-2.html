Project 2: Hour of Code

Role · Student Year · 2026 Coding activity
HOUR OF CODE </> ABSTRACT ACTIVITY PREVIEW

Overview

Hour of Code introduces programming through a short, approachable activity. It offers a way to explore how instructions, order, and logic work together to make a task or idea happen.

What it explores

Working through a coding activity means translating a goal into small steps, checking what each instruction does, and adjusting the sequence when the result is different than expected. It makes abstract coding ideas easier to explore through practice.

Tools & skills

  • Coding concepts
  • Sequencing
  • Logic
  • Problem solving
