Project 3: Robotics

Role · Student Year · 2026 Robotics
ROBOTICS R ABSTRACT PROJECT PREVIEW

Overview

Robotics brings computation into the physical world. This project area is about exploring how a system can sense, respond, and carry out actions, while connecting technical ideas with hands-on learning.

Learning through testing

Hands-on robotics encourages an iterative approach: try an idea, observe the result, and use that feedback to understand what could work better. It develops patience and problem solving while making the relationship between software and physical systems tangible.

Tools & skills

  • Robotics
  • Systems thinking
  • Testing
  • Iteration
